## ⚠️ Points d'Attention / Technical Debt

1. **`escapeHtml`** dans `BilanAnnuelServiceImpl` : remplacement `"` → `\"` fait manuellement (pas de librairie). OK pour usage interne.
2. **Numérotation pages Word** : champ `PAGE` / `NUMPAGES` insérés mais pas testés sur Word réel. À valider.
3. **Oracle JDBC** : nécessite Oracle Maven Repository ou Maven Central (disponible depuis 21c). `ojdbc11` résout depuis Maven Central.
4. **H2 mode Oracle** : `DATABASE_TO_UPPER=false` nécessaire pour éviter la conversion majuscules des noms de tables/colonnes.
5. **Sécurité** : endpoints `/api/synthese/**` non protégés par `@PreAuthorize` pour l'instant.
6. **Pas de tests** : aucun test unitaire/IT pour les nouvelles fonctionnalités.
7. **Intérims** : données de test créées mais pas encore intégrées dans `UserDetailsServiceImpl` (Phase 2).
8. **Triggers Oracle** : `date_mise_a_jour` géré par triggers (pas de `ON UPDATE CURRENT_TIMESTAMP` natif).
